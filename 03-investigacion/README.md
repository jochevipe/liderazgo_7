## Formato de citas del informe

Por decisión del equipo, usar **IEEE**: citas numéricas entre corchetes, como [1], y referencias ordenadas por primera aparición, reutilizando el número cuando se repita la fuente. La numeración debe unificarse al integrar todas las secciones del informe. Las fichas de investigación conservan sus identificadores internos (por ejemplo, MT01), que no sustituyen los números de cita.
