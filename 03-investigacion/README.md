## Formato de citas del informe

Por decisión del equipo, usar **IEEE**: citas numéricas entre corchetes, como [1], y referencias ordenadas por primera aparición, reutilizando el número cuando se repita la fuente. La numeración de las secciones actuales se centraliza en [10-referencias.md](../04-informe/10-referencias.md). Los anexos de investigación conservan sus numeraciones locales cuando se indica. Las fichas de investigación conservan sus identificadores internos (por ejemplo, MT01), que no sustituyen los números de cita.
