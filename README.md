# Proyecto de investigación y difusión sobre bienestar

## Objetivo y audiencia
Investigar y comunicar una temática de bienestar físico y mental relacionada con el ejercicio, la alimentación saludable y el sueño, para estudiantes universitarios. Este repositorio organiza el trabajo; no presupone conclusiones ni una plataforma elegida.

## Requisitos de la clase
La referencia es [clases/ppt-8.pdf](clases/ppt-8.pdf), módulo 2, diapositivas 7–14:

- **7–9:** indicaciones del trabajo grupal y presentación del proyecto de investigación y difusión sobre bienestar.
- **10:** cinco entregables: informe, publicación digital, presentación de avances, campaña de difusión y presentación final.
- **11:** contenido requerido para el informe; ver [informe/README.md](informe/README.md).
- **12:** publicación digital en formato didáctico; ver [difusion/README.md](difusion/README.md).
- **13:** campaña para invitar a la publicación e interacción con la audiencia para conocer sus opiniones; la consigna contempla un blog, un podcast o un foro, sin que se haya elegido una modalidad.
- **14:** lluvia de ideas: definir el objetivo, generar y registrar ideas, organizarlas, identificar motivaciones comunes y valorar su viabilidad.
