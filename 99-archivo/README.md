# Archivo de versiones anteriores

Se conservan estos antecedentes para consultar versiones previas sin confundirlas con los documentos de trabajo.

| Carpeta | Contenido y motivo de conservación |
| --- | --- |
| `planificacion-preliminar/` | Primer esquema con actividades A01–A12: [planificación](planificacion-preliminar/planificacion.md), [RACI](planificacion-preliminar/raci.md), [Gantt](planificacion-preliminar/gantt.md) y [horas](planificacion-preliminar/presupuesto-hh.md). El esquema detallado T01–T17 está en [02-planificacion](../02-planificacion/README.md). |
| `planificacion-generada/` | Copias de [Word](planificacion-generada/planificacion-proyecto.docx) y [Excel](planificacion-generada/planificacion-gantt-raci.xlsx) que ya existían antes de la incorporación de los cinco archivos del equipo. Son distintas de las copias incorporadas y se preservan sin cambios. |
| `historial-asistente/` | Registros históricos de [creación de la base](historial-asistente/base-del-proyecto.md) y [planificación del módulo 2](historial-asistente/planificacion-modulo-2.md). Describen trabajo anterior del asistente y no acreditan el estado actual ni acuerdos nuevos del equipo. |

Las copias de planificación incorporadas por el equipo están en [02-planificacion/documentos-equipo](../02-planificacion/documentos-equipo/README.md). Ninguna copia se declara aprobada por este ordenamiento.
