# Coordinación del equipo

Este documento se basa en los "tips a considerar" de ppt-9, diapositiva 11, y en el tema de coordinación de ppt-8, diapositivas 2–5. Los acuerdos se completan **cuando el equipo los tome**.

## Acuerdos de trabajo (por completar)

| Tip (ppt-9, diap. 11) | Acuerdo del equipo |
| --- | --- |
| **Reuniones de trabajo:** definir días y horario | Día y hora: — · Modalidad: — |
| **Minuta de reuniones:** puntos conversados y acuerdos, enviados por email, WhatsApp, etc. | Canal: — · Quién la redacta: por turnos (ver abajo) |
| **Roles:** definirlos según el trabajo | Ver la [matriz RACI](04-matriz-raci.md) |
| **Definir responsables:** cada tarea con un responsable y equilibrio en las tareas | Ver la [RACI](04-matriz-raci.md) y el [presupuesto HH](06-presupuesto-hh.md) |
| **Definir tareas realizables:** que se puedan hacer en el plazo y sean tangibles | Ver el [listado de tareas](02-listado-de-tareas.md) |
| **Timing:** entregas de información relevante para todo el equipo | Plazo para avisar atrasos: — |
| **Seguimiento de acuerdos:** al cerrar o iniciar una reunión y entre reuniones | Revisar la tabla de acuerdos al inicio de cada reunión |
| **Cambios:** ante imprevistos, reorganizar, priorizar y cumplir compromisos | Todo cambio de fechas o responsables se anota en la minuta |
