# Difusión

Según las diapositivas 12–13 de [clases/ppt-8.pdf](../clases/ppt-8.pdf):

- **Publicación digital:** presentar la investigación en un formato didáctico.
- **Campaña de invitación:** convocar público a visitar la publicación.
- **Interacción con la audiencia:** la consigna contempla un blog, un podcast o un foro para recoger opiniones reales sobre la temática; la modalidad queda pendiente de decisión.

El formato y las plataformas de publicación, campaña e interacción están pendientes de decisión. Registrá las devoluciones solo cuando se hayan recibido; no las completes con ejemplos inventados.
